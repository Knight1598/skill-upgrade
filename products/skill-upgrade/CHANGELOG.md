# Changelog

## 0.1.0 — 2026-09-25

- First version: picks the skill that just ran, lists concrete misses from that run, and fixes each with one minimal edit in the skill's real source, never the installed plugin cache.
- Adds one regression eval per fixed miss, bumps the version, and reports in 8 lines or fewer.
- Asks one question instead of guessing when no skill ran or no miss is visible.
